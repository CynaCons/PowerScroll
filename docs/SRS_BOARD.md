# SRS: Board pages

**Project:** PowerScroll
**Version:** 0.83.4
**Date:** 2026-10-14

## Purpose

Board pages are a separate notebook page kind for lightweight task flow. They
are persisted with the notebook but are not a canvas and do not participate in
canvas undo history.
